# 494. Target Sum

**Recorded:** 2026-10-16

## Pattern

Subset-sum dynamic programming (DP), also called the knapsack pattern.

## Approach

Split the numbers into a plus group and a minus group. If the plus group sums to P and the minus group sums to M, then P minus M equals the target and P plus M equals the total. Adding the two equations gives P equal to (target + total) / 2, so the problem becomes counting the subsets that sum to (target + total) / 2.

Two guards come first: if the target is larger than the total, the answer is zero, and if (target + total) is odd, the answer is zero, because no integer subset sum can be a half.

The dynamic programming table is defined one cell at a time in plain words: `dp[w]` is the number of ways to reach sum w using the items processed so far. The table starts with `dp[0] = 1` and every other cell at 0. For each number `num`, walk the table backwards from the target sum down to `num` and add the two cases: `dp[j]` (the ways to reach j without num) plus `dp[j-num]` (the ways to reach j minus num without num, and then num joins). His phrasing for the table was adopted verbatim: "subset+1 slots, one for everybody".

The final code is correct.

## Complexity

- Time: O(n times target), where n is the number of items.
- Extra space: O(target) for the one-dimensional table.
