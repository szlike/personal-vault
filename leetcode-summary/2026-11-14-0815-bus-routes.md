## Pattern

Model **bus routes** as BFS nodes: each route costs one bus to board. Build a `stop → routeIndices[]` index; start from routes containing `source`, and traverse route-to-route via shared stops.

```js
function numBusesToDestination(routes, source, target) {
  if (source === target) return 0;
  const stopToRoutes = new Map();
  routes.forEach((stops, route) => stops.forEach(stop => {
    if (!stopToRoutes.has(stop)) stopToRoutes.set(stop, []);
    stopToRoutes.get(stop).push(route);
  }));
  if (!stopToRoutes.has(source) || !stopToRoutes.has(target)) return -1;
  const queue = [], seenRoutes = new Set(), seenStops = new Set();
  for (const route of stopToRoutes.get(source)) { queue.push(route); seenRoutes.add(route); }
  let head = 0, buses = 1;
  while (head < queue.length) {
    const size = queue.length - head;
    for (let i=0; i<size; i++) {
      const route = queue[head++];
      for (const stop of routes[route]) {
        if (stop === target) return buses;
        if (seenStops.has(stop)) continue;
        seenStops.add(stop);
        for (const next of stopToRoutes.get(stop) ?? []) {
          if (!seenRoutes.has(next)) { seenRoutes.add(next); queue.push(next); }
        }
      }
    }
    buses++;
  }
  return -1;
}
```

## Complexity

With indexed stops, visiting each route and stop mapping a bounded number of times gives roughly O(total route-stop entries + routes) time/space, ignoring hash-map constant factors.

## Past mistakes and feedback

- **Observed:** Confused 2D route structure and whether BFS levels represent stops or buses.
- **Observed:** Incorrect increment of bus count and missing `source===target` or missing-stop checks.
- **Observed:** A `continue` in the wrong place risked a loop that made no progress; duplicates were prevented too late.
- **Feedback:** Mark routes visited **on enqueue**, use a head index rather than `shift()`, and optionally dedupe stops.

## Points to improve

1. Define BFS node and unit cost *before* writing traversal.
2. Dry-run `[[1,2,7],[3,6,7]]`, `source=1,target=6` → 2 buses.
3. Draw queue contents at each level and show where `buses++` happens.
4. Explain route-level vs stop-level BFS and how each counts cost.
